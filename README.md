# Customer Behavior Analysis | SQL, Python & Power BI

## 📌 Project Overview

The **Customer Behavior Analysis** project focuses on understanding customer purchasing patterns, identifying behavioural trends, and generating meaningful business insights using SQL, Python, and Power BI.

The project follows an end-to-end data analytics workflow, starting with raw data cleaning and preprocessing, followed by exploratory data analysis, SQL-based business analysis, and interactive dashboard development.

## 🎯 Project Objectives

- Understand customer purchasing behaviour and trends.
- Identify meaningful patterns from customer data.
- Perform data cleaning and preprocessing.
- Answer business-related questions using SQL.
- Create an interactive Power BI dashboard.
- Generate insights to support data-driven business decisions.

## 📂 Project Workflow

### 1. Data Collection
- Imported the customer dataset.
- Explored the dataset structure, columns, and data types.
- Analysed approximately 1,000–10,000 records.

### 2. Data Cleaning & Preprocessing (Python)
- Used Python and Pandas for data cleaning.
- Handled missing and duplicate values.
- Checked and corrected data types.
- Prepared the dataset for further analysis.

### 3. Exploratory Data Analysis (EDA)
- Explored customer data to understand patterns.
- Analysed important customer-related metrics.
- Identified trends and relationships within the dataset.

### 4. SQL Business Analysis (MySQL)
- Connected the cleaned dataset to MySQL.
- Developed and executed 10–15 business-related SQL queries.
- Used SQL operations to filter, aggregate, and analyse customer data.
- Extracted insights to answer business questions.

### 5. Power BI Dashboard
- Connected the analysed data to Power BI.
- Created interactive visualizations.
- Developed dashboard views to monitor customer behaviour and business trends.
- Presented key findings through charts, graphs, and KPIs.
